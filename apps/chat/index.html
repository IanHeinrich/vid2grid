                  Connection

                  Any OpenAI-compatible API works, on your own computer or hosted. Pick one to fill in its base URL, or type your own.

                  The key is kept in this browser's localStorage and sent only to the base URL. Venice needs one; a local server usually does not.

                  A local server must allow this page's origin (CORS): for Ollama set OLLAMA_ORIGINS, and in LM Studio turn on CORS in the server settings.

                      Audio labels

                      One label per line, either name or name: wording; wording. The wordings describe the same sound in different ways and results show the name, as in music: a band playing; someone singing.

                      Descriptive phrases such as a crowd laughing work better than single words. Similar labels compete with each other, so keep them distinct.

                      Background sounds soak up quiet or ambient stretches and are never reported. Labels stay in this browser; changing them re-checks sounds the next time audio is analysed.
